# 一键角色卡写卡器

## 项目定位

这是一个面向零基础用户的酒馆助手后台脚本项目。脚本通过按钮打开一个覆盖酒馆页面的独立 iframe 工具，默认只要求用户回答三个角色问题；高级用户仍可编辑世界观、多角色素材、开场白和状态栏图片。脚本把酒馆当后台 API 使用，保留现有模块化 APP 与软格式校验，并吸收
`src/玉藻前2.0` 的生成内核、长文本蒸馏、续传、目标角色卡写入和 IndexedDB 草稿能力，完成生成、写入、校验、恢复和绑定。

## 核心边界

- 不是新建一套预设，也不是调用酒馆当前启用预设；而是把 `src/秋青子写卡预设/秋青子写卡预设.json`
  适配成脚本内置的组装预设。
- `【一般条目】` 到 `【/MVU条目】` 整段不作为固定外壳复刻；这段知识只在对应任务调用时按需内置。
- 上述区间之外的原预设条目按原顺序、原启用状态、原角色身份复刻到 `generateRaw({ ordered_prompts })`。
- 用户模块输入插入原预设的 `🔓 继续-Kemini` 位置，即替换其中的 `{{lastUserMessage}}`。
- 原预设中的酒馆 builtin 占位（角色定义、世界书、聊天历史等）不传入
  `ordered_prompts`；生成时只使用脚本组装的提示词、用户模块输入和任务知识。
- 思维链段保留原标签结构和位置，但适配为简短任务自检，不要求模型输出完整隐藏推理；前端解析时只取 `<content>` 内的成品。
- 只学习 `src/秋青子写卡预设/伪IDE/index.ts` 的打开方式：脚本按钮、全屏 iframe、Vue 挂载、样式隔离、关闭卸载。
- 不复用伪 IDE 前端页面，不使用 `src/wtc`。
- `src/玉藻前2.0`
  中与世界观、人设、开场白、长文本蒸馏和续传有关的业务提示词按原任务语义迁入；已有调色盘知识、资源 JSON 和角色知识保持原内容。
- 生成目标在确认执行前始终是本地草稿；只有用户确认后，才会创建或打开目标角色卡并开始写入。

## 一键流程

1. 用户点击脚本按钮打开写卡器；如果没有打开角色卡，可以直接在工具内创建并自动打开空白角色卡。
2. 默认进入新手工作流，回答角色核心点子、与玩家的关系、期待的聊天体验三个问题；世界背景可交给系统自动安排。
3. 高级编辑模式保留完整世界观、多角色、状态栏素材和详细模块编辑能力；“只生成人设”仍是不会修改角色卡的独立工具。
4. 进入编辑页或填写内容时只修改 IndexedDB 草稿，不创建世界书、不绑定角色卡，也不写入任何外部内容；2.0 旧草稿会在首次读取时自动迁移。
5. 世界观或角色素材超过长文本阈值时，先按 2.0 流程分段蒸馏，再用多轮摘要合并成生成上下文，避免直接截掉用户素材。
6. 人设完成后进入独立开场白步骤，可选择内置风格并编辑大纲；开场白在确认执行前同样只保存在草稿中。
7. 点击生成后先显示执行确认，明确目标角色卡、目标世界书、角色数量、开场白写入、连接模式和预计生成次数。
8. 用户最终确认后，第一阶段保存目标角色卡、世界书、后台脚本、局部规则和绑定关系作为恢复点；恢复点成功后才允许后续写入。
9. 第一次 AI 调用按原预设适配壳与世界观知识生成世界背景；之后按角色顺序逐次调用角色人设与调色盘知识，最后生成开场白。
10. 生成支持“稳定完整”“流式保活”“截断续传”三种连接模式。续传模式会检测输出完整性、去除重叠片段并安全合并，每 5 次续传暂停一次等待用户确认。
11. 每个阶段完成后立即安全写入；生成中既可请求“完成当前步骤后停止”，也可立即停止，失败后可以从当前阶段重试或撤销本次生成。
12. 缺少 `<role_result>`、`<worldview_result>`、`<opening_result>`
    或子标签时不再中断生成。原始输出完整保留，前端显示格式提醒，并可通过“校验并矫正”规范标签后重新解析和刷新写入内容。
13. 前端按世界书配置规则写入：

- 世界观：蓝灯，角色定义前，order 1。
- 角色速览：蓝灯，角色定义前，order 4。
- 单角色卡：角色详细条目蓝灯，角色定义后。
- 多角色卡：角色速览蓝灯，角色详细条目绿灯。
- 二次解释：D0 system。
- EJS 多阶段人设：角色定义后，order 99。
- 所有写入条目禁止递归、防止进一步递归。

14. 固定生成 MVU：

- MVU 运行脚本：把外部 `酒馆助手脚本-MVU.json` 写入目标角色卡脚本库并启用。
- 变量结构脚本：写入目标角色卡脚本。
- 初始变量：世界.当前时间、世界.当前地点、每个角色.好感度。
- 变量更新规则。
- 变量列表。
- 变量输出格式。
- 变量输出格式强调。

15. 后 4 个外部正则写入目标角色局部正则并启用；脚本另生成状态栏显示正则与占位符隐藏正则，按角色数量接入 `stat_data.*`。
16. 开场白写入目标角色卡首条消息，并确保结尾恰好包含一个
    `<StatusPlaceHolderImpl/>`；用户导入图片时，将图片写入目标角色卡头像。
17. 全部阶段完成后进入交付页，提供格式检查、返回修改、重新生成、恢复生成前版本，以及确认并打开目标角色卡。

## 数据归属

| 数据                       | 存储位置                                 | 生命周期       | 备注                                     |
| -------------------------- | ---------------------------------------- | -------------- | ---------------------------------------- |
| 表单、模式、头像、开场白   | IndexedDB `one-click-card-writer/drafts` | 当前未完成工程 | 仅本地草稿，兼容迁移 2.0 旧草稿          |
| 世界观、人设、MVU、EJS     | 目标世界书                               | 目标角色卡     | 确认执行后才写入                         |
| 首条开场白、头像           | 目标角色卡                               | 目标角色卡     | 使用显式目标名称，不依赖隐式 `current`   |
| MVU 后台脚本、变量结构脚本 | 目标角色卡脚本库                         | 目标角色卡     | 确认执行后安装并启用                     |
| 局部正则                   | 目标角色卡正则库                         | 目标角色卡     | 包含 4 个外部资源和状态栏规则            |
| 生成前恢复点               | 当前运行内存                             | 单次生成       | 覆盖角色卡、世界书、脚本、正则和绑定关系 |

## 文件规划

- `index.ts`：脚本入口和全屏 iframe 挂载。
- `App.vue`：应用状态、草稿、生成流程、暂停、失败恢复和格式校验编排。
- `types.ts`：内部数据类型。
- `ui-types.ts`：前端工作阶段和格式检查类型。
- `components/BeginnerWorkspace.vue`：三个问题的新手写卡工作区。
- `components/OpeningWorkspace.vue`：开场白风格、大纲和执行前检查工作区。
- `components/ContinuationDialog.vue`：每 5 次自动续传后的人工确认界面。
- `components/CompletionView.vue`：生成完成后的交付中心。
- `components/CreateCharacterDialog.vue`：无当前角色时创建并打开空白角色卡。
- `components/RestoreConfirmDialog.vue`：恢复生成前版本的确认界面。
- `utils/presetAdapter.ts`：秋青子原预设结构适配器。
- `utils/generation.ts`：世界观、角色、开场白、长文本蒸馏、流式保活和截断续传调用。
- `utils/draft.ts`：IndexedDB 草稿读写和 2.0 旧草稿迁移。
- `utils/parser.ts`：解析 AI 输出。
- `utils/formatValidation.ts`：软格式校验、标签别名识别和确定性矫正。
- `utils/artifacts.ts`：标签、MVU、EJS、状态栏和世界书条目生成。
- `utils/worldbook.ts`：世界书创建、绑定、写入。
- `utils/character.ts`：目标角色卡创建/打开、头像、首条消息和角色脚本写入。
- `utils/recovery.ts`：生成前快照和角色卡、世界书、脚本、正则、绑定关系恢复。
- `utils/regex.ts`：外部 MVU 正则导入、状态栏显示/隐藏正则写入。
