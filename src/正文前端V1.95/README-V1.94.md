# 正文前端 V1.94 · Vector Edition

V1.93 的独立副本。旧版源文件不变，只启用一个版本的正文渲染脚本，避免两版同时接管同一楼层。

## 固定正文占位（2026-10-27）

正文 iframe 挂在 `.mes_text` 内的正文原位，只替换完整的 `<content>…</content>` 或
`<maintext>…</maintext>`。块外的其他标签、按钮、状态栏和独立前端继续由酒馆及其原有插件处理；不隐藏整块
`.mes_text`，也不把外围内容搬进正文前端。

脚本启动时，`engine/narrative-display-rule.ts` 自动在当前角色卡的局部正则首位安装「正文前端 V1.94
· 正文占位」，并启用当前卡的局部正则。规则只作用于 AI 消息的显示，不应用于发送给模型的提示词；其他规则的内容、顺序和单项启用状态保持原样。重复启动时不会重复安装。分发目录同时提供可单独导入的
`正文占位显示正则.json`。

这条规则在完整的正文块前后分别放置 `.bp-narrative-slot-v194` 和
`.bp-narrative-end-v194`，中间保留原文供酒馆正常格式化。前端直接挂在前一个固定占位里，只隐藏这两个标记之间的正文。`engine/content-slot.ts`
不再遍历文字、匹配整段正文、识别其他组件标签，也不再做多轮定时查找。卸载脚本或查看原文时恢复中间的正文；固定标记本身没有可见界面。

生成期间不创建正文窗口。等待生成结束或停止后统一读取楼层，再原位挂载；即使 `</content>`
已输出，尾部仍在生成时也继续等待。解析结果按楼层、消息原文和 swipe 缓存；编辑、切换回答或切换聊天时更新缓存。台词标记解析后将说话人映射存入消息数据，并在同一次写入中从正文移除对应标记，避免它们随历史正文再次发给 AI；前端继续从缓存读取说话人和聚焦人物。

DOM 监听只处理楼层列表和固定占位的变化；正文块外的其他组件更新不再触发正文解析。保留原有 GAL／气泡内部解析及显示功能；其他独立功能标签应放在
`content`／`maintext` 外部。

`阿洛娜.png`，由 `modules/AronaAssistant.vue` 统一等比展示，不以 SVG 重绘替代。

单独维护舞台装饰；仍不嵌入原版 UI 图片。人物立绘保持原资源、等比缩放及底部站位，不改变剧情、角色数据和交互事件。
