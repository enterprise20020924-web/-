# 如月银行

从校园地图左侧「如月银行」进入整页，返回时保留原地图 DOM、缩放、平移与目录状态。

## 确定的规则

- 年利率 2.8%，30 个 AI 正文楼层为一期，12 期为一个计息年。一般一问一答情况下，360 个正文楼层对应约 720 个聊天消息楼层。
- 玩家输入、系统消息、0 楼开局和纯变量更新不计；同一楼的重 roll 不另算一次。
- 普通合同每期还等额本金，利息按实际剩余本金及经过正文楼层计算。
- 如月诗乃好感度 ≥80 时可以选择到期一次还清；资格只在内部判断，UI 不出现好感度、阈值或解锁说明。签约后还款方式记入合同。
- 提前还款不收未来利息或手续费。单期借款不显示分期进度。
- 到期自动从「物品系统._天海信用点」支付；余额不足保留应还金额，本轮没有增加罚息或补助政策。
- 金额支持自行输入，1～12 期。借款额度上限尚未设定；金额快捷项只是输入便利，不是额度分级。
- 货币结算到小数点后两位，楼层间利息保留精度直到实际付款。

## 数据与实现

- `loan.ts`：纯计息模型、正文计数、借款及还款。
- `runtime.ts`：沿用最新 MVU 楼层事务，监听 MVU 写入前事件；AI 提示禁止重复处理银行天海信用点。
- 银行账本放在 `_amamiState.bank`，独立于 Zod 的 `stat_data`；按楼层和 swipe 保存，借还款与天海信用点同次提交。旧 `_amamiBank` 自动迁移，继承和清理由 `state/` 统一处理。
- `KisaragiBankPage.vue` / `bank.css`：页面、试算、合同切换、当前借款与还款计划。
- `BankPanelArt.vue`：SVG 面板边框、斜切与几何装饰；数字和控件仍由 HTML 渲染。
- 银行素材加入现有图片预载清单。战斗晚到的天海信用点结算按差额合并，保留期间产生的银行交易。
