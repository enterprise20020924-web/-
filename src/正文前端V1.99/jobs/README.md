# 招工启事

入口位于校园地图「辣妹24」下方，与银行、商店一样整页替换地图；返回时恢复原地图视角。

背景使用仓库 `llm1/天海附加背景/信息服务中心.png`，已加入公共图片预加载清单。

`catalog.ts`
集中维护第一批六个岗位、职责与地图地点：礼物屋、精品店、中央食堂、海之家、图书馆、后山温泉。地下市场和赌场不在招聘范围内。

- 类别按钮筛选岗位，点击启事查看职责。
- 「在地图查看」打开对应地点详情，沿用地图原有前往流程。
- 「向诗乃咨询」将岗位咨询填入聊天输入框，返回正文，由玩家发送。
- 本轮实现招聘浏览与咨询；报酬、工作时长、经验奖励和正式入职/结算尚待数值设计。本页不写入任务、资金或楼层账本。

页面样式通过地图 ShadowRoot 注入。窄屏采用「岗位列表 → 详情」切换，保留顶部柜台背景。
