# 辣妹24

- 地图快捷入口位于「如月银行」下方，沿用蓝白 SVG 横幅与店员头像取景。
- 店面整页替换地图；返回时保留地图位置、缩放和目录。左侧陈列商品，右下方柜台区域结算，避开店员面部及招手动作。
- 使用 GitHub `enterprise20020924-web/-/llm1/天海附加背景/辣妹24.png` 原图；加入原有图片预载清单。
- `Gyaru24Page.vue` 通过原 `ShopPage.vue` 的 `storefront` 插槽复用商品、售价、天赋折扣与购买函数。普通手机补给站仍使用原界面，不另建第二套商品数值。
- 支持商品分类、搜索、装备等级筛选、持有数量、数量选择和购买。装备单次购买一件，沿用原有逻辑；永久提升用品沿用原购买后自动使用的规则。
- `Gyaru24Storefront.vue` 与 `gyaru24.css` 负责店面；`ProductGlyph.vue` 提供 SVG 分类图标。图标用于区分商品类别，并非原游戏的商品素材。
- 窄屏按背景、商品、结算区纵向排列。

实际组件预览位于 `.codex-artifacts/gyaru24-ui/`，购买验证使用隔离的演示存档，不修改玩家聊天。演示购买 2 件原价 200 的耐力药剂后，天海信用点从 5000 变为 4600，背包新增数量 2。
