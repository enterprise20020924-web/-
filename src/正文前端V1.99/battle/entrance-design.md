# 对战登场演出

目标是从正文选择人物自然进入战斗：左侧玩家、右侧对手，人物面部是主视觉，姓名留在画面下缘。沿用蓝、青、白的战斗界面配色，采用平滑色面、SVG 轨道与斜切遮幕，不引入噪点纹理或额外图片生成。

## 实际参考

- 用户提供的《异环》视频：`C:/Users/Administrator/Videos/Captures/异环   2026-10-28 04-50-50.mp4`，12.951 秒。实际展示排球赛程／编队切换；提取蓝青色幕布覆盖、左右宽色带滑入、圆形轨道背景。关键帧保存到 `.codex-artifacts/battle-intro-reference/transition-contact.png`。
- [P3R 开战转场提取视频](https://www.youtube.com/watch?v=NTH0TizGZ0M)：实际查看 0.25、0.55、0.9、1.4、2.2 秒；提取斜线拓宽、纯色色面覆盖、短暂停顿和斜向揭幕。为非官方上传，不复制其角色素材。
- [FGO 实机开战片段](https://www.youtube.com/watch?v=eIGsllCtqPs&t=160s)：实际查看 160 秒 BATTLE / 1/3 中央定格及 165 秒战场。提取大字定格与细光线，给双方姓名和立绘留出阅读时间。为非官方上传。

## 实现

1. 点击发起后，同楼层舞台显示开场，同时准备战斗 iframe。
2. ENCOUNTER 由中央细光线、分段轨道与多条字片组成，约 900ms 完成拼合定格；文字和遮幕沿斜面向两侧退开，接入双方立绘左右错峰切入。SVG 轨道与单次星形冲击支撑中央 VS，保持原有约 3 秒的对峙演出。
3. 战场准备好后，从 VS 中心扩展出斜切光线与三层色面；BATTLE / START 从相反方向撞入，配合描边回声、单次扩散环及短促定格。800ms 后左右斜角幕布退场，在 760ms 内完整露出正在淡入的战场，不再用整屏半透明蓝雾覆盖。
4. 演出完全结束后释放战斗初始化等待，启动 BOSS 首句对白和开场机制。

BattleEntrance.vue 负责已确认的双方立绘画面及总时序；EntranceEncounter.vue、EntranceBattleStart.vue 分别封装开头和收尾演出。InlineBattleView.vue 负责等待战场、跳过／返回／重新进入与 iframe 生命周期。新 session 的 entrancePending 只消费一次，恢复历史对手配置不会重播。正式战斗数值、全身立绘、同层切换方式保持现有实现。

立绘解析采用严格名字／本体别名，不按前缀借用其他人物图。未知玩家用现有性别对应默认立绘；未知对手无图时以姓名字形占位。窄屏仍保留左右关系，收小辅助文字；减少动效模式缩短过渡并停止持续轨道转动。
