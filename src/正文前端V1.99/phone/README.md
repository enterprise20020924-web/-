# SKYLINK 悬浮手机 · V1.99

来源为 `src/性斗学园测试版/性斗学园脚本/components/StatusBarWrapper.vue`，即带动态主页与多种悬浮入口样式的 SKYLINK 学园终端。`terminal/source-manifest.json` 记录一次性迁入的 64 个依赖文件；之后直接维护 fork 副本，不在构建时覆盖它。

`tools/build-narrative-phone.mjs` 编译 `terminal/entry.ts`，提取全部手机 CSS。正文构建器把模块与 CSS 压缩到 `generated/phone-bundle.ts`。运行时 `runtime.ts` 解压模块，在正文脚本的 Tavern Helper 环境中加载，并把手机挂在酒馆主文档的独立 Shadow Root。只导入正文 fork 的 `index.js` 即可，不需要再安装手机脚本。

悬浮手机只挂一份，不随正文楼层重复创建。原手机位置、壁纸、头像、第二 API、NovelAI 配置和后街世界书沿用原键；不会输出或复制 API Key 到源码。原本体的数值维护不迁入、不重复执行。fork 显示手机时暂时隐藏原脚本的手机壳，卸载后还原。已有后街主线桥由本体继续提供；缺少桥时 fork 注册自己的桥，并在卸载时清理。

接入调整包括：版本页改为随正文更新；手机内部生成不注入正文 dialogue_map／开局提示；切换聊天关闭手机窗口、清理页面上下文；商店拖动使用实际宿主窗口的尺寸及事件；资料页释放头像更新监听。

文字、标签、输入框和状态色统一使用 `terminal/shared/skylink-contrast.scss` 中的主题变量。普通内容使用 `--sk-ink` / `--sk-muted`，实色按钮必须同时使用 `--sk-action` / `--sk-on-action`；不能用整块透明度表示禁用、已完成或未解锁状态。午夜主题为语义色提供独立的浅色前景。

手机配色只保留湖蓝和午夜，旧暮粉、玻璃偏好读取为湖蓝。手机复用正文的 `useNarrativeChatTheme`：正文切到午夜时同步午夜，切回日间时同步湖蓝；手机隐藏时同样接收变化，重新加载时会对齐已经启用的正文午夜。手机内仍可手动选择这两种配色，手动选择不改变正文主题。

悬浮入口使用 GitHub `llm1/全身立绘` 中的 Q 版透明素材：湖蓝为阿洛娜、午夜为普拉娜，直接跟随手机当前主题。桌面按用户追加要求放大到 256 × 256px，手机端保持 120 × 120px；拖动边界按当前端的实际尺寸计算，保留位置记忆与点击/键盘打开。两张图同时加载并加入图片预载清单，切换角色不再等待首次下载；原圆球与旧入口皮肤选项已移除。

2026-11-11 已完成四种主题的页面、详情和弹层检查，以及 390px 窄屏的悬停、焦点和禁用状态检查，并重新生成包含手机的正文脚本。范围和结果见 [CONTRAST-AUDIT.md](./CONTRAST-AUDIT.md)。
