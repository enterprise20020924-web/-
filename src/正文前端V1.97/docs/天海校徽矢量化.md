# 天海 AMAMI 校徽矢量化

## 外观基准

- 参考：`vector/assets/amami-reference.png`，5741 × 2620。
- 复刻目标：原 `AmamiMark.vue` 已拼好的 AMAMI 校徽，保留 `viewBox="245 237 3620 2188"`。
- 月牙、轨道、四个圆点、AMAMI 五个字母的位置和裁切沿用原组件，字母不替换为字体。
- 颜色继续由 `currentColor` 控制，正文青蓝色、星盘浅色及其原有外部光效沿用原样。

## 矢量来源

`tools/trace-amami-mark.py`
在原始分辨率上复现旧组件的亮度遮罩、裁切和字母位移，再描摹为贝塞尔轮廓。正式版本使用 32 个透明度层、原尺寸绘图区和 0.08 的曲线优化参数。透明度层使用加法混合，整组形成矢量 alpha 遮罩，最后一次性施加
`currentColor`，保留月牙柔边及轨道的浅色过渡。

正式 SVG 中只有路径、矩形和矢量遮罩，没有
`<image>`、PNG、JPEG 或外部图片引用。原始参考 PNG 仅用于重新描摹，不进入当前正文或星盘构建。

## 文件

- `vector/assets/amami-mark.svg`：完整、独立、可直接打开的纯 SVG。
- `vector/AmamiMark.vue`：正文与星盘共用的显示组件。
- `vector/generated/amami-vector-data.ts`：SVG 路径文本的 gzip 压缩数据，不是压缩图片。
- `vector/amami-vector.ts`：一次解压、共用路径。
- `天赋星盘预览/embedded-amami-data.ts`：嵌入模式读取宿主传入的同一份数据，避免在正文包内重复携带。
